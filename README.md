# Cybersecurity Risk Assessment – BrightLayer Stores

##  Project Overview

This project presents a **basic cybersecurity risk assessment** for a simulated small business, **BrightLayer Stores**, with 8 employees.

The assessment follows the standard cybersecurity risk flow:

**Asset → Threat → Vulnerability → Risk → Recommendation**

The goal is to identify important business assets, understand potential threats and weaknesses, assess their possible impact, and recommend practical security improvements.

##  Scenario

BrightLayer Stores uses:

- Employee email accounts
- Shared computers
- A company website
- Cloud storage containing invoices
- User passwords
- A public Wi-Fi router

## Assessment Areas

### 1. Important Assets
The assessment identifies five key assets:

- Employee email accounts
- Shared computers
- Company website
- Cloud storage with invoices
- User passwords

### 2. Potential Threats

The main threats considered are:

- **Phishing attacks** – Attempting to steal employee credentials.
- **Malware attacks** – Compromising computers and business information.
- **Zero-day attacks** – Exploiting previously unknown security weaknesses.

### 3. Vulnerabilities

The assessment identifies:

- Weak or reused passwords
- Unpatched software and systems
- Poorly secured Wi-Fi infrastructure

### 4. Associated Risks

These vulnerabilities could lead to:

- Unauthorized account access
- Theft or exposure of sensitive business information
- Loss of invoices and other data
- Malware infections
- Website compromise
- Business disruption

### 5. Security Recommendations

Recommended security improvements include:

- Enable **Multi-Factor Authentication (MFA)**
- Use strong and unique passwords
- Keep systems and software updated
- Implement endpoint protection
- Secure the Wi-Fi router and use a separate guest network
- Provide phishing awareness training
- Restrict access to sensitive cloud data
- Maintain regular backups

##  Objective

The objective of this project is to demonstrate a **practical, beginner-level approach to cybersecurity risk assessment** by identifying what needs protection, how it could be compromised, the potential business impact, and how those risks can be reduced.

##  Skills Demonstrated

- Cybersecurity Risk Assessment
- Asset Identification
- Threat Identification
- Vulnerability Assessment
- Risk Analysis
- Security Recommendations
- Security Awareness
- Basic Incident/Risk Thinking

## Disclaimer

This is a **simulated cybersecurity assessment** created for learning and portfolio purposes. No real organization or systems were tested.
